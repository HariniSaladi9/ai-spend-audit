# FAQ

## 1. What does this tool do?

AI Spend Audit analyzes your current AI tooling costs and recommends ways to reduce unnecessary spending while maintaining similar capabilities.

---

## 2. Do I need to create an account?

No. Users can complete an audit without creating an account or logging in.

---

## 3. Which AI tools are supported?

The platform currently supports:
- ChatGPT
- Claude
- Cursor
- GitHub Copilot
- Gemini
- OpenAI API
- Anthropic API
- Windsurf

---

## 4. How are savings calculated?

Savings recommendations are generated using rule-based pricing comparisons, team-size analysis, and usage-fit recommendations.

---

## 5. Is my company information public?

No. Public audit URLs remove identifying company and email information before sharing.
